# 서울제일교회 주차관리

교인 차량 등록, 예배별 주차 신청, 관리자 승인·입차 확인을 하는 웹 앱입니다.

- **화면**: GitHub Pages (무료 정적 호스팅)
- **데이터**: Google 스프레드시트
- **서버(API)**: Google Apps Script 웹 앱 (무료)

```
교인/봉사자 휴대폰 ──▶ GitHub Pages (index.html, admin.html)
                           │  fetch (POST)
                           ▼
                  Apps Script 웹 앱 (apps-script/Code.js)
                           │
                           ▼
                  Google 스프레드시트 (차량 / 주차신청 / 주차구역 / 예배)
```

## 기능

| 교인 화면 (`index.html`) | 관리자 화면 (`admin.html`) |
|---|---|
| 차량 등록 (이름·연락처·차량번호·교구 등, 개인정보 동의) | 날짜·예배별 신청 목록, 구역별 정원 현황 |
| 연락처로 내 차량 불러와 주차 신청 (날짜·예배·구역) | 승인 / 반려 / 구역 변경 / 안내 메모, 대기 일괄 승인 |
| 구역별 잔여 대수 실시간 표시, 정원 마감 시 신청 불가 | **입차 확인**: 차량번호 뒤 4자리로 검색 → 입차 처리 |
| 내 신청 조회 · 취소 | 등록 차량 검색, 사용 정지 / 삭제 |

신청 상태: `대기` → `승인` → `입차` (또는 `반려`, `취소`)

## 설치 방법

### 1단계 — 구글 시트 + Apps Script

1. [Google 스프레드시트](https://sheets.new)에서 새 시트를 만들고 이름을 `서울제일교회 주차관리`로 정합니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 `Code.gs` 내용을 모두 지우고 이 저장소의 [`apps-script/Code.js`](apps-script/Code.js) 내용을 붙여넣고 저장합니다.
4. 위쪽 함수 선택에서 **`setup`** 을 고르고 **실행**합니다. 처음에는 권한 승인 창이 뜹니다 (고급 → 안전하지 않은 페이지로 이동 → 허용).
5. 실행 로그에 나오는 **초기 관리자 비밀번호**를 메모합니다.
   - 변경: Apps Script 왼쪽 ⚙️ **프로젝트 설정 → 스크립트 속성 → `ADMIN_PASSWORD`**
6. 시트로 돌아가 **주차구역**(구역 이름·정원)과 **예배** 시트를 실제 교회 상황에 맞게 수정합니다. (처음 값은 예시입니다)

### 2단계 — 웹 앱 배포

1. Apps Script 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
2. 설정
   - 다음 사용자로서 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
3. **배포** 후 나오는 **웹 앱 URL** (`https://script.google.com/macros/s/.../exec`)을 복사합니다.

> Code.js 를 수정한 경우 **배포 → 배포 관리 → ✏️ → 버전: 새 버전 → 배포** 를 해야 반영됩니다. (URL은 그대로 유지)

### 3단계 — GitHub Pages

1. GitHub에서 새 저장소를 만들고 이 폴더의 파일을 올립니다.
2. [`config.js`](config.js) 의 `API_URL` 에 2단계 URL을 넣고 커밋합니다.
   ```js
   window.APP_CONFIG = { API_URL: 'https://script.google.com/macros/s/XXXX/exec' };
   ```
3. 저장소 **Settings → Pages → Build and deployment**
   - Source: **Deploy from a branch**, Branch: **main** / **(root)** → Save
4. 1~2분 후 `https://<아이디>.github.io/<저장소이름>/` 로 접속합니다.
   - 교인용: `.../index.html` (주보·주차장 안내판에 QR 코드로 게시 추천)
   - 관리자: `.../admin.html`

## 데모 모드

`config.js` 의 `API_URL` 이 비어 있으면 **데모 모드**로 동작합니다. 서버 없이 같은 로직(`apps-script/Code.js`)을
브라우저에서 실행하며, 데이터는 그 브라우저에만 저장됩니다. (관리자 비밀번호: `admin`)

로컬에서 미리 보기:

```bash
python3 -m http.server 8000
```

## 설정 변경 (`apps-script/Code.js` 상단 `CONFIG`)

| 항목 | 기본값 | 설명 |
|---|---|---|
| `AUTO_APPROVE` | `false` | `true`면 정원이 남아 있을 때 신청 즉시 승인 |
| `MAX_DAYS_AHEAD` | `60` | 오늘부터 며칠 뒤까지 신청 가능 |
| `MAX_VEHICLES_PER_PHONE` | `5` | 연락처당 최대 등록 차량 수 |

## 시트 구조

| 시트 | 열 |
|---|---|
| 차량 | 등록ID, 등록일시, 이름, 연락처, 교구/부서, 차량번호, 차종, 색상, 메모, 상태(정상/정지), 수정일시 |
| 주차신청 | 신청ID, 신청일시, 날짜, 예배, 구역, 차량번호, 이름, 연락처, 비고, 상태, 관리자메모, 처리일시, 자리번호 |
| 주차구역 | 구역, 정원, 안내 — 자리번호는 위에서부터 정원만큼 차례대로 매겨짐 (주차장1: 1~7, 주차장2: 8~11, 주차장3: 12~15, 주차장4: 16~18) |
| 예배 | 예배명, 시간 |

시트에서 직접 값을 고쳐도 앱에 바로 반영됩니다. 열 순서는 바꾸지 마세요.

## 보안·개인정보 참고

- 교인 화면은 **연락처 + 차량번호**가 일치해야 신청·취소할 수 있습니다. 연락처를 아는 사람은 해당 연락처의 차량·신청 내역을 볼 수 있으므로, 주민번호 등 민감한 정보는 받지 않습니다.
- 관리자 기능은 서버에서 비밀번호를 확인합니다. 추측하기 어려운 비밀번호를 쓰고 담당자가 바뀌면 변경하세요.
- 구글 시트는 공유하지 말고 관리 담당자 계정만 접근하도록 두세요. 실제 데이터는 시트에만 저장되며 GitHub에는 올라가지 않습니다.
